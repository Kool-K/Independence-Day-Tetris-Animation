# 🇮🇳 India's 80th Independence Day – Tetris Flag Animation 🎆

A stunning, interactive web animation created to celebrate **India's 80th Independence Day**! Watch Tetris blocks drop, stack seamlessly, and reveal the vibrant Indian Tricolor Flag (Tiranga) complete with the Ashok Chakra and dynamic fireworks celebrations.

## ✨ Features

- 🧱 **Tetris-Style Animation**: Classic Tetris tetrominoes fall into place with precision to construct the Indian Flag block by block.
- 🎵 **Audio Sync & Audio Visualizer**: Integrated music player (`song.mp3`) with live audio spectrum visualizers and beat detection.
- 🎆 **Interactive Fireworks**: Exploding tri-color fireworks celebrate the completion of the flag.
- 🌌 **Parallax & Glassmorphism Design**: Modern aesthetic featuring mouse parallax, subtle backdrop blurs, and neon tricolor gradients.
- 📱 **Responsive & Smooth**: Built with pure Vanilla JavaScript and HTML5 Canvas for high performance on modern web browsers.

## 🛠️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Kool-K/Independence-Day-Tetris-Animation.git
cd Independence-Day-Tetris-Animation
```

### 2. Run Locally
Open `tetris.html` in your favorite web browser (Chrome, Edge, Firefox, Safari):

- **macOS**: `open tetris.html`
- **Windows**: `start tetris.html`
- **Linux**: `xdg-open tetris.html`

*(Alternatively, serve using any local static file server like Live Server in VS Code or `npx serve`)*.
